# AIC Mod 0.3.1

AliceInCradle 的功能调整 Mod。

---

## 前置要求

**本 Mod 是 BepInEx 插件，必须先给游戏装好 BepInEx 才能使用。**

- 游戏根目录（含 `AliceInCradle.exe` 的那层）下必须已存在 `BepInEx` 文件夹，且其中含有 `core\BepInEx.dll`
- 若尚未安装 BepInEx，请先按 BepInEx 官方说明为游戏安装（本 Mod 不含 BepInEx 本体）
- 确认游戏能正常启动、`BepInEx\LogOutput.log` 有输出后，再安装本 Mod

没有 BepInEx 时，本 Mod 不会生效，游戏也不会有任何变化。

---

## 安装

1. 确认已完成上面的前置要求
2. 把压缩包内 `BepInEx` 文件夹的内容，覆盖到游戏根目录的 `BepInEx` 下
3. 启动游戏
4. 进游戏后按 `F8` 打开界面

装好后结构：

```
<游戏根目录>\
  BepInEx\
    core\BepInEx.dll          ← 原有的，未改动
    plugins\AICMod.dll        ← 本 Mod
    config\moc.buhtig.reganam-nimda-diov.cfg   ← 本 Mod
```

卸载：删掉上面两个本 Mod 的文件即可。

## 功能

### 杖强化

`PrCaneEquip.Set` 里 14 项属性，每项都是 **原版算出的值 + 你设的偏移量**。
默认值等于原始手改版本（战斗类 +1、锁定性能 +5、消耗类不加）。

| 项 | 说明 |
|---|---|
| 近战威力 / 霰弹威力 / 近战范围 / 近战速度 | 近战相关 |
| 咏唱准备速度 / 远程威力 / 锁定性能 | 施法与锁定 |
| 稳定性 / 中和性能 / 咏唱速度 / 过蓄速度 | 施法参数 |
| MP 消耗比 / 锁定后消耗 / 魔力溅射率 | 消耗类，加正值会更费蓝 |

改完在游戏里数值不会立刻刷新，点界面底部的 **`刷新当前杖数值`**，或重新装备一次杖。

### 难度

- **危险度倍率**：1.00 ~ 10.00，1.00 = 原版
- **永夜模式**：`isNight()` 恒为真

### 敌人数量

- **追加数量倍率**：乘在每场召唤的动态追加数量上，1.00 = 原版
- **额外追加数量**：直接加在同一个值上
- **连脚本固定数量一起放大**：勾上后 `%EN` 脚本里写死的数量也乘倍率，并放宽同屏上限

### 食物效果

- **上限倍率 / 起点**：`最终值 = 起点 + 原值 × 倍率`，用于突破原版食物效果 100% 的上限
- **饱腹值上限**：原版 28
- **食物效果调试器**：点 `○ 打开食物效果调试器` 打开独立窗口

调试器界面：

| 区域 | 内容 |
|---|---|
| 左栏 | 28 项效果输入，单项范围 ±10，0 = 不生效。**打开时默认全部为 100（即每项都填 10）** |
| 中栏 | cost（饱腹值）输入 1~999，默认 1，以及四个按钮 |
| 右栏 | 当前已生效的效果等级，×100 即百分比 |

四个按钮：

- **Apply**：把效果应用到自己身上
- **Clear Effect**：清空当前食物效果
- **Clear Field**：把所有输入复位为 0
- **CreateDish**：生成对应料理掉在脚下

## 配置

配置文件：`BepInEx\config\moc.buhtig.reganam-nimda-diov.cfg`

全部设置都在 `[General]` 一节，界面里改和直接改文件等效，改完立即生效。

| 键 | 默认 | 范围 |
|---|---|---|
| `UiKey` | F8 | 任意按键 |
| `UiShowOnStart` | false | 进入游戏后自动显示界面 |
| `DangerMultiplier` | 2 | 1 ~ 10 |
| `AlwaysNight` | true | 开 / 关 |
| `EnemyCountMultiplier` | 2 | 0 ~ 10 |
| `EnemyCountAdd` | 0 | 整数 |
| `EnemyCountScaleScript` | false | 开 / 关 |
| `FoodCapMultiplier` | 1 | 1 ~ 100 |
| `FoodCapStart` | 0 | 0 ~ 100 |
| `FoodCostMax` | 999 | 1 ~ 9999 |
| `CaneEnabled` | true | 开 / 关 |
| 14 项杖属性 | 见上表 | −1 ~ 10 |

## 注意事项

- **危险度会连带影响敌人数量**。危险度同时喂给敌人数量公式，所以调高危险度倍率敌人也会变多。想单独测敌人数量，先把危险度倍率放回 1.00。
- **食物效果的攻击类加成有已知限制**。`ATK` / `ATK_MAGIC` / `near_shotgun_power` 这几项写入了也会在游戏内部被夹到 100%，面板数值会变，实际伤害不变。要提升伤害请用杖强化里的 `近战威力` / `远程威力` / `霰弹威力`，那几项不受此限制。
- **杖强化改动需要刷新**。游戏对已装备的杖有缓存，改完数值要点 `刷新当前杖数值` 或重新装备。
- **调试器的改动不写存档**。食物效果是临时状态，会随饱腹值消耗而衰减，读档后不保留。
- **`FoodCostMax` 和 `FoodCapMultiplier` 是两回事**。前者是胃容量（一次能吃进多少 cost），后者是单项效果能叠多高。
- 与其它修改了同类功能的 Mod 同时使用时，注意 `isNight` / `getDangerLevel` / `Stomach` 这类方法的补丁叠加。

## 日志

启动后 `BepInEx\LogOutput.log` 应出现：

```
[Info   :   BepInEx] Loading [AIC Mod 0.3.1]
[Info   :    AICMod] AICMod 0.3.1 已加载：补丁 10/10 成功。按 F8 打开界面（可在配置里改键）。
```

`10/10` 表示全部补丁挂载成功。若数字小于 10，下一行会指明失败的补丁。
